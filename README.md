# Druk Cinema Admin Dashboard

A responsive black, orange and gold admin dashboard built with HTML, CSS and JavaScript.

Open `dist/index.html` in a browser, or serve `dist` using any static web server.

Features include an overview, sample revenue and occupancy charts, searchable bookings, CSV reports, a movie library with status filters, movie creation, and a sample showtime schedule. Movie changes persist in browser local storage.

This is a frontend demo using sample data. Authentication, real bookings, payments, and a backend are not implemented. Sites hosting provides private access to the published demo.

The supplied logo was processed using the built-in image generation tool with this prompt: “Remove all white background including internal white spaces, leaving actual alpha transparency. Preserve exact orange ornamental ticket border and gold central symbol, proportions and colors. Crop canvas closely around the entire mark with small padding. No added elements or text.” The transparent output is saved at `dist/assets/druk-logo.png`.
